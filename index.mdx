The Cobalt Game SDK connects your game to the Cobalt Launcher. You can identify the signed-in player, publish rich presence, record achievements and statistics, synchronize saves, accept launch and invite context, enrich captures, and participate in Cobalt-managed distribution.

<Warning>
  This is an example wiki for an SDK that is still being designed. Names, packages, capabilities, and signatures shown here are a proposed contract, not a released API.
</Warning>

## How it works

Your game talks to the installed Cobalt Launcher through a local, authenticated connection. The launcher owns the player session and communicates with Cobalt services. Account tokens never enter your game process.

```text
Your game → Cobalt Game SDK → Cobalt Launcher → Cobalt services
```

If Cobalt is unavailable, SDK calls return stable result codes and your game continues normally. Do not make the SDK a requirement for starting or playing your game.

## Planned capability groups

| Group | What it enables |
| --- | --- |
| Core | Connection state, feature negotiation, callbacks, diagnostics |
| Player | Public profile and account-change events |
| Activity | Accurate sessions, playtime, presence, and pause state |
| Progression | Achievements, counters, statistics, and personal bests |
| Storage | Declared cloud-save sets, checkpoints, and conflict handling |
| Social | Parties, invitations, and join context with player consent |
| Media | Capture context, screenshots, clips, and metadata |
| Launch | Safe launch arguments, build channels, and deep-link payloads |
| Distribution | Official installs, updates, and community `.clgame` packages |

## Choose an integration

The native C ABI is the compatibility layer for every engine integration.

- Use the [C and C++ quickstart](/quickstart) for custom engines.
- Use the [Unity integration](/integrations/unity) for C# projects.
- Use the [Unreal Engine integration](/integrations/unreal) for Unreal projects.

The initial platform targets are Windows x86-64, Linux x86-64, and macOS universal binaries. Steam Deck and Proton support use an authenticated local fallback when a Windows game cannot reach the launcher's native Unix socket.
