# Cobalt Game SDK Wiki

This Mintlify site is an example documentation set for the planned Cobalt Game SDK. The API, packages, capabilities, `.clgame` schema, and `cobalt://` routes are provisional until their implementations are finalized.

## Preview locally

Install the Mintlify CLI, then run it from this directory:

```bash
npm install --global mint
mint dev
```

Open `http://localhost:3000`.

## Validate changes

```bash
mint validate
mint broken-links --check-anchors
```

Keep example APIs explicitly labeled as provisional until the corresponding SDK contract is implemented.
